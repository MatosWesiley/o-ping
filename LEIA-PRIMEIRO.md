# Ping 0.5 — comece aqui

1. Leia **GUIA.md** antes de instalar.
2. Instale o APK de teste fornecido separadamente. Android 8 ou superior.
3. Para login real, execute o servidor Python incluído com `--setup`; não há servidor hospedado nem senha padrão.
4. Configure o endereço do computador no aplicativo, entre como organização e crie as equipes.
5. Atletas e técnicos não precisam de aprovação nesta versão de apresentação. O técnico cria sua equipe; o atleta entra pela aba Equipe. Só organizadores precisam de aprovação.
6. Prepare os aparelhos online antes de demonstrar a troca por proximidade sem internet.

`PREVIA-PING.html` mostra a mesma interface com **exemplos** no navegador, sem autenticação,
Bluetooth ou notificações reais. Ela não comprova o funcionamento no Android.

**Não desinstale um aplicativo anterior com dados importantes.** Uma atualização exige
a assinatura original; este APK preserva a chave de teste das entregas 0.3/0.4 desta sessão.

O APK foi compilado, mas instalação, WebView, permissões, GPS, notificações e Nearby A → B → C
ainda precisam de teste em aparelhos físicos. Consulte **VALIDACAO.md**.

Já usa a versão anterior? Atualize também os cinco arquivos do servidor, incluindo o novo `attachments.py`,
preservando banco, chave privada, pasta de anexos e ambiente Python. Consulte GUIA.md.
